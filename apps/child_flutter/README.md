# Child Flutter app

Flutter iOS/Android shell for the child learning experience. The P0 slice only
proves the application boundary and contains no camera, authentication, local
database or child data. The app boundary references the shared contract at
`packages/contracts/openapi.yaml`; ChildProfile and Device types must be
generated from that contract after ADR-0002 is approved, not hand-copied here.

```bash
flutter pub get
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
```

`pubspec.lock` is generated by the pinned Flutter SDK and is checked in.
