# Prompt：企业级代码审查

审查范围：`{{WORKING_TREE | COMMIT | BRANCH | PR}}`：`{{REF_OR_LINK}}`

请阅读 `AGENTS.md`、`AI_CONTEXT.md`、`PROJECT.md`、相关 `TASK.md`/PRD/ADR 和测试规则，然后审查变更，不修改文件。

重点检查：

- 是否真正满足验收标准，是否存在静默行为变化。
- 权限绕过、注入、敏感信息、文件/URL 输入、依赖和供应链风险。
- 数据一致性、迁移、并发、幂等、事务、重试和回滚。
- 错误路径、空值、边界条件、资源释放和可观测性。
- API、事件、配置和数据格式的向后兼容。
- 测试是否能在修复前失败、是否遗漏关键路径或只验证实现细节。
- 是否混入范围外重构、生成物、调试代码或无关格式化。

输出规则：

1. 先列发现，按 `Critical / High / Medium / Low` 排序；只报告可操作且有证据的问题。
2. 每条包含：标题、严重级别、文件/位置、触发条件、实际影响、证据、最小修复方向和建议测试。
3. 不把偏好、纯风格差异或无实际影响的猜测包装成缺陷。
4. 若没有发现，明确写“未发现可报告问题”，并说明仍未覆盖的验证盲区。
