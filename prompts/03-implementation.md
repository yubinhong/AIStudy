# Prompt：按任务实现并验证

请执行 `TASK.md` 中状态为 `READY` 或 `IN_PROGRESS` 的当前任务，直到达到 Definition of Done。

工作协议：

1. 先读取 `AGENTS.md`、`AI_CONTEXT.md`、`PROJECT.md`、`TASK.md`，再读取任务关联的 PRD、架构、测试、安全和 ADR。
2. 检查工作区和相关实现，确认任务目标、范围、验收标准和禁止改变项；若存在冲突，先报告。
3. 简单任务直接实现；复杂任务按 `PLANS.md` 逐里程碑推进并持续更新 Progress、Discoveries 和 Decision Log。
4. 修改保持最小、可审查并沿用现有模式。不得顺手重构、升级无关依赖、改变公开 API、清理他人改动或跳过校验。
5. 新行为补测试；缺陷先添加可失败的回归测试。优先运行最小相关测试，再运行 `TESTING.md` 要求的质量门槛。
6. 检查权限、数据迁移、并发、错误路径、日志、性能、兼容和回滚；发现范围外问题写入 `TODO.md`。
7. 更新受影响的文档、ADR、契约和 `CHANGELOG.md`。在 `TASK.md` 填写完成记录并逐项核对验收标准。
8. 不提交、不推送、不部署，除非我明确授权。

停止规则：所有验收标准满足且验证通过时停止；若需要新的产品决策、外部权限、破坏性操作或显著扩展范围，停止并报告唯一阻塞点，不要猜测。

最终汇报只包含：完成结果、关键文件、验证命令与结果、未执行项、剩余风险和建议的下一任务。
