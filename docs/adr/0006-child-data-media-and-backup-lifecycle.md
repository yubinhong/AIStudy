## Context

孩子档案、学习记录和题目图片属于 Confidential 或 Restricted 数据。产品要求最小采集、图片短期保存、家庭导出/删除和不向 Provider 发送无关内容；适用法域、监护人同意、精确保留期限、备份擦除与 Provider 数据处理条款尚未决定。

## Decision Drivers

- 真实儿童数据进入系统前必须有可执行、可审计的生命周期规则。
- 删除不能只删除主表，必须覆盖对象、缓存、向量、导出与备份处理说明。
- 本地开发、测试和 AI 评测只能使用合成或经批准脱敏数据。

## Considered Options

1. 不限期保存图片和学习数据，按需人工清理。
2. 只在客户端保存，服务器不支持导出或删除。
3. 分类最小化、目的限制、短期媒体保留、异步导出/删除状态机与受控备份策略。

## Decision

提议选择选项 3。数据按 `SECURITY.md` 分类；ChildProfile 只收集产品必需字段，题目图片使用私有对象存储、随机键、最短批准期限和派生对象联动删除。导出和删除由重新验证的家长发起，经历 `requested → verified → processing → completed/failed`，且全程审计。删除范围包括业务库、对象、缓存、检索向量和已生成导出；备份采用加密、最小权限和批准的“到期不可恢复或受控擦除”策略。精确法域、同意机制、保留数值、备份处理与 Provider 区域/训练退出在 TODO-005 前不得假定为已批准。

## Consequences

### Positive

- 生命周期有可验证边界，降低过度保留与错误完成报告的风险。
- Capture 和 AI 功能可在真实数据接入前明确所需审批。

### Negative / Trade-offs

- 导出、删除和备份将增加工作流、审计与运维复杂度。
- 短期媒体保留可能限制后续人工复查，需要产品明确告知。

### Risks and Mitigations

- 风险：删除遗漏派生对象或备份；缓解：资源清单、异步状态、失败可见、定期演练和不得虚报完成。
- 风险：Provider 再利用或跨区域处理数据；缓解：先完成条款/区域/退出评审，最小化或去标识输入。

## Compatibility and Migration

- 兼容性：当前合成 Profile/Device 数据不代表真实儿童数据策略；本 ADR 不批准真实数据写入。
- 迁移步骤：先完成法域和同意决策，定义数据目录/保留任务/导出删除 API，再接入 Capture 或家庭试用。
- 回滚：保留删除审计和失败状态；出现风险时停止新数据采集与 Provider 传输，优先前向修复而非恢复已删除数据。

## Validation

- 用合成数据演练导出、删除、媒体过期、缓存/向量清理、备份恢复和删除状态报告。
- 在真实数据前由安全/法务 Owner 审核法域、同意、保留、第三方处理和用户告知。
