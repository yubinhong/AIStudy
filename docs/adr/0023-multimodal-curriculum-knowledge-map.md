# ADR-0023：教材原页多模态理解与可审核知识图谱

- 状态：`Accepted`
- 日期：`2026-07-23`
- 决策者：项目 Owner（用户；根据真实 118 页教材解析与任务推荐结果要求立即整改）
- 关联：`PLAN-0018`、`ADR-0004`、`ADR-0020`、`ADR-0021`、`ADR-0022`、`FR-011`、`FR-020`
- 替代/细化：替代 ADR-0021 中“页级纯文本足以供家长审核”的产品假设，以及 ADR-0022 中直接从页级文本规则抽题的推荐来源；保留私有原件、家长发布、来源键、家长批准和 Provider Adapter 边界。

## Context

真实小学数学 PDF 包含插图、方框、连线、涂色、物体位置和跨行排版。`pdfplumber` 只能抽出文字流，导致“在少的后面画……”“把……放在……下面”等内容失去图形主语，页面虽然显示“识别置信度 100%”，语义实际上不完整。旧推荐又从这些残缺文本中按问号和关键词抽题，最终产生无法理解甚至题干错误的任务。

原始 PDF 并未丢失，仍在家庭私有 MinIO；丢失的是解析结果中的视觉语义。继续优化文本清洗不能恢复图形关系，需要把原页视觉纳入教材理解，同时避免把对象键、MinIO 地址或整本无界内容交给模型。

## Decision

1. 原始 PDF 继续私有保存。服务端用 `pypdfium2==5.11.0` 在家庭基础设施内逐页渲染有界 JPEG 预览，保存到私有 `curriculum-previews/` 前缀；家长和孩子只能通过 Session 鉴权 API 读取，不返回对象键或存储 URL。
2. 教材分析 worker 按最多 4 页一批，将页图和该页本地抽取文字发送给同一个获批 NewAPI 视觉模型。模型返回严格 JSON：章节/小节、页面摘要、知识点观察、学习目标、先修关系和带视觉说明的练习候选。教材内容始终是不可信数据，不得成为 Prompt 指令。
3. 服务端再把所有页级结构化摘要发送给云模型做一次全书归纳；第二阶段只能引用服务端签发的页码和练习来源键，不能新编教材题。服务端验证页码、来源键、数量和 Schema 后保存知识图谱草稿。
4. `CurriculumKnowledgeMap` 和规范化 `CurriculumKnowledgePoint` 保存全书摘要、章节、知识点、目标、先修关系、来源页和练习证据。家长在 Web 查看原页与知识图谱后显式批准；只有批准的知识图谱可以进入 Tutor 和任务推荐。
5. 推荐不再从 `CurriculumChunk.text` 直接规则抽题。它读取已批准知识点及其练习证据，把知识点摘要与全部开放错题交给 NewAPI 做关联和计划；正式知识点、题目、页码和原页均由服务端按来源键回填，任务仍需家长批准。
6. 已发布旧 Snapshot 可在不修改其不可变发布事实的前提下生成并批准新的派生知识图谱；新上传 PDF 默认自动排队分析。Provider 不可用时保留原 PDF、原页预览和本地文字，明确显示分析失败，不生成占位知识点或任务。

## Dependency

新增直接依赖 `pypdfium2==5.11.0`。它由活跃维护的 pypdfium2 项目提供 Python 绑定，包本身采用 Apache-2.0/BSD-3-Clause，内含 PDFium 二进制采用 BSD-3-Clause；当前已作为 `pdfplumber` 传递依赖锁定，本决策将其提升为直接依赖，避免运行时依赖传递关系。替代方案 PyMuPDF 带 AGPL/商业许可边界，Poppler CLI 增加系统镜像依赖，均不采用。

## Safety, Cost and Audit

- 单页预览不超过 2 MiB，Provider 单图沿用有界压缩；每批最多 4 页、整本最多 400 页、单次只使用一个 Provider。
- Provider 请求不包含儿童身份、对象键、URL 或原始 PDF；只包含教材页图、页码、本地文字和后续结构化摘要。教材授权声明和 Provider 数据条款仍由家庭 Owner 负责确认。
- 每批与全书归纳记录 Provider/模型、Prompt/Schema 版本、输入输出指纹、状态、延迟和可获得的 token/成本；不记录页图、教材原文或模型原始响应。
- 删除教材时级联数据库分析事实，并删除原 PDF 和全部预览对象。失败对象必须可重试清理。

## Compatibility and Rollback

- 新增 `0025_curriculum_knowledge_map`，不删除 `CurriculumChunk` 或既有 Recommendation/Task；旧客户端忽略新字段。
- 部署顺序：迁移 → API/解析 worker/分析 worker → Web → Flutter。回滚时关闭分析 worker和知识图谱推荐，保留新增表与已批准事实，不破坏性 downgrade。
- 旧页级文字仍可作为搜索辅助，但 UI 不再把它标成完整教材页面，推荐不得把残缺文本直接作为教材原题。

## Validation

- 固定教材页覆盖纯文字、位置关系、分与合、涂色/连线、跨页章节和扫描页；原页预览与页码一致。
- 模型输出覆盖 Schema 错误、伪造页码/来源键、Prompt 注入、重复知识点、缺页、超时、成本上限和中途重试。
- 家长可查看全书摘要、章节、知识点、目标、原页和视觉依赖练习；未批准图谱不能进入 Tutor/推荐。
- 推荐必须证明错题到已批准知识点的关联，并向孩子端提供完整题干、来源页和需要时的教材原页。
