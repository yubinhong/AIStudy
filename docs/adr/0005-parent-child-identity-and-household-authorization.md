## Context

家庭是最高优先级的数据隔离边界。P0 合成切片以 demo headers 测试了 Parent/Child 与跨 Household 404，但这不是生产认证。孩子不应被强制要求手机号；同时家长需要可撤销的设备访问、恢复和高风险操作再验证。

## Decision Drivers

- 每一次资源读取和写入都必须在服务端验证 Household、角色和设备。
- 降低儿童身份数据收集，并支持共用家庭设备与 iPad/Android 离线使用。
- 防止 ID 枚举、令牌泄露、失窃设备与越权管理操作。

## Considered Options

1. 仅用客户端角色选择或共享长期 API 密钥。
2. 要求每个孩子使用手机号/第三方社交登录。
3. 家长账户拥有 Household；孩子使用家长设置的 PIN 与可撤销设备凭证；服务端执行资源授权。

## Decision

提议选择选项 3。家长账户是 Household 的所有者和管理主体；孩子以最小身份使用 PIN 解锁的、绑定 Household 与 ChildProfile 的可撤销设备凭证。服务端从认证主体解析 actor、role、Household 和设备，再逐资源授权；跨 Household 统一返回 404。访问令牌保持短期，设备凭证可轮换、撤销和恢复；导出、删除、成本/模型策略与设备撤销要求重新验证和审计。IdP 供应商/自建方案、精确 TTL、MFA 和恢复流程仍待安全 Owner 批准；demo headers 只能用于 local/CI。

## Consequences

### Positive

- 家庭与孩子的身份职责清楚，不需要儿童手机号。
- 可在失窃、退出或家庭变更时撤销单个设备。

### Negative / Trade-offs

- 需要安全存储、PIN 防暴力破解、设备注册/恢复和会话轮换实现。
- 家长恢复会成为高风险流程，需要明确支持与审计边界。

### Risks and Mitigations

- 风险：跨家庭 ID 枚举；缓解：授权优先于资源披露、404 语义、反向测试和审计告警。
- 风险：PIN 或设备凭证被滥用；缓解：限速、失败锁定、平台安全存储、可撤销凭证与重新验证。

## Compatibility and Migration

- 兼容性：当前 demo headers 仅为测试适配器；不得映射为 staging/production 认证。
- 迁移步骤：在真实数据/身份接入前定义 OIDC/自建选择、令牌声明、设备注册、撤销和审计契约；替换 demo adapter。
- 回滚：认证变更采用并行验证和短期兼容窗口；发现授权问题时撤销设备/会话并关闭受影响写入，不降级到 demo headers。

账号密码认证的实际迁移、引导管理员、会话、孩子账号和恢复边界见 ADR-0017。

## Validation

- 每个资源测试同家庭允许、异家庭 404、角色不足、过期/撤销设备、缺失主体和 ID 枚举。
- 演练 PIN 失败限速、设备恢复、重新验证和审计字段脱敏。
