# ADR-0029：家长后台加载 SmartEdu 电子教材

- 状态：`ACCEPTED（2026-09-10，真实 PDF 诊断后由项目 Owner 要求修复）`
- 日期：`2026-09-09`
- 关联：`TASK-0012`、`PLAN-0044`、`ADR-0021`、`ADR-0023`、`ADR-0018`

## 背景

家长目前需要先用独立工具取得国家中小学智慧教育平台 PDF，再回到 AIStudy 上传。上游 `tchMaterial-parser`（MIT）已经验证了公开目录版本文件、教材详情 `ti_items`、`ti_storage/ti_storages` 和 `cs_path:${ref-path}` 的解析方式。AIStudy 需要降低操作步骤，但不能把第三方资源、登录令牌或版权判断直接交给孩子端或模型。

## 决策

在家长后台增加 SmartEdu 目录选择和“加载为草稿”入口：

1. API 只接收目录返回的 `resource_id`，固定访问 `s-file-*.ykt.cbern.com.cn` 元数据域名和 `r[1-3]-ndr-private.ykt.cbern.com.cn` PDF 域名，拒绝任意 URL、非 HTTPS、未知主机、非 PDF、重定向后的未知主机、超过 50 MiB 的响应和缺少 PDF 文件头的响应。
2. 适配器使用标准库 HTTP 客户端、无环境代理、有界超时和最多三个固定镜像候选。默认不需要任何配置；严格私有 CDN 资源要求登录时，家长可在页面粘贴从本人 SmartEdu 登录会话取得的一次性 JSON。JSON 至少包含 `access_token`，`mac_key` 和 `diff` 可省略；有 `mac_key` 时 API 按每个受信 URL 生成短时 HMAC-SHA256 `X-ND-AUTH`，没有时兼容上游的占位头。凭据只在当前下载请求内存中使用，Web 仅临时放在当前标签页 `sessionStorage`，刷新或连续加载时可复用，手动清除/退出登录/关闭标签页后清除；不写入数据库、日志、镜像、Git 或返回值。字段错误、控制字符或时钟差越界时返回稳定错误。未填写或平台仍拒绝凭据时明确失败，家长仍可使用本地 PDF 上传。
3. 下载得到的文件计算 SHA-256 后写入家庭私有 MinIO，保存 `source_provider=smartedu` 与平台资源 ID；不向 Web/API 响应返回第三方 PDF URL、对象键或签名 URL。来源文件生成现有 `uploaded` 草稿并进入原 `material-parse-worker`、家长原页审核、知识图谱批准和发布门禁。
4. 目录只展示小学一至六年级的数学/语文元数据。目录标题、版本、学期、年级和学科均是不可信输入；服务端导入时重新解析详情并核对用户选择，教材正文和文档指令不能成为系统 Prompt。
5. 家长必须确认自己有权使用、不对外分发且文件不含儿童个人信息；“跨家庭精确内容复用”仍需单独勾选，并沿用已批准知识图谱门禁。上游教材版权、平台条款和法域义务不因 AIStudy 代码许可改变。

## 取舍与后续

本轮沿用现有上传请求的同步有界下载，解析仍由 durable worker 异步完成；后续如真实教材下载耗时影响体验，再以独立 source-download job/进度接口替代，不能通过放宽读取上限解决。SmartEdu 凭据通常有时效性，页面把主动粘贴的 JSON 临时保存于当前标签页 `sessionStorage`，并在手动清除、退出登录或关闭标签页后删除；服务端对同一孩子/资源的幂等键先查询已有导入回执，命中时在下载前回放，避免网络重试重复取得 PDF。AIStudy 不保存或共享凭据。页面同时提供从 SmartEdu 登录页控制台获取 JSON 的具体步骤。正式版权/教研、Provider 质量和设备回归仍需独立验收。

## 回滚

移除目录/导入路由、Web 入口和适配器即可停止新来源；保留已有私有教材和学习事实。数据库使用前向修复清理来源字段，不能通过 downgrade 删除已导入的教材、解析页或学习记录。
