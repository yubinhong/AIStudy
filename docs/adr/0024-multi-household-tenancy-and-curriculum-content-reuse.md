# ADR-0024：全局超级管理员、多家庭边界与教材内容复用

- 状态：`Accepted`
- 日期：`2026-07-28`
- Owner：项目 Owner + API/Web 负责人
- 决策者：项目 Owner（2026-07-28 确认先支持亲戚家庭与国家公开教材复用）
- 关联：`PLAN-0019`、`TODO-216`、`TODO-217`、`ADR-0017`、`ADR-0018`、`ADR-0023`
- 替代/被替代：细化 ADR-0017 的“单家庭自用”限制；不替代现有 Household 授权语义

## Context

当前 API 资源路径与业务事实已带 `household_id`，但 Web BFF 曾固定默认 Household，首次引导只支持单个本地 `admin` 家庭。亲戚家庭需要独立登录、孩子和学习数据，不能共享默认 Household。

教材上传原本按孩子对象键保存。同一本国家公开教材会重复保存原件、渲染页图和分析结果。无条件跨家庭全局哈希去重会错误共享私有教材，并可能通过响应行为泄露其他家庭是否使用某个文件。

## Decision Drivers

- Household 必须继续是儿童学习数据、授权、审计和删除的强租户边界。
- 同一家庭的家长可安全复用自己已确认授权的教材原件，孩子的审核、发布和学习事实仍独立。
- 向亲戚或商业用户开放前，必须有可撤销成员关系、恢复、TLS、限速、审计、数据保留和支持流程，不能复用单家庭 `admin` 引导。
- 删除任一孩子教材不能删除另一个孩子、另一个家庭或仍被复用的私有对象。

## Considered Options

1. 保持每孩子完全独立教材对象，并在当前 Web 上开放多家庭注册。
2. 对任何上传文件按全局内容哈希共享 PDF、页图和知识图谱。
3. 仅对家长显式声明的国家公开教材，按完整内容指纹复用私有对象与已审核派生结果；家庭、审核和学习事实仍独立。

## Decision

选择选项 3。

1. 每个登录用户名在整个自托管实例内唯一，已认证 Session 的 `household_id` 是 Web BFF、API 和 Flutter 请求的唯一家庭作用域。实例中只存在一个 `super_admin`，默认引导账号 `admin` 迁移为该角色；它可创建新 Household 及其首个普通 `parent`。新家庭没有管理员角色，普通家长只能创建、管理自己名下孩子的档案和唯一孩子登录账号，孩子用户名仍全局唯一。普通家长和孩子均不能创建家长或家庭；本实现不提供账号跨家庭切换、邀请、成员移除或公开注册。
2. 只有上传时家长明确勾选“国家公开教材，可跨家庭复用”的 PDF 才参与复用。服务端完成流式哈希、MIME 与尺寸校验后，以 `(content_sha256, media_type, byte_size)` 精确匹配；来源教材必须仍是显式可复用且其知识图谱已经批准。匹配结果只在私有导入事务内使用，接口与页面不披露来源家庭、对象键或是否命中。
3. 命中时新家庭/孩子创建自己的 `LearningMaterial`、`CurriculumSnapshot`、知识图谱和知识点记录，并复制来源的页级解析与知识图谱内容为 `needs_review` 草稿；原 PDF 与私有页图对象可共享。目标家庭必须自行审核、发布后才会用于 Tutor/推荐。任务、错题、复习、账号、审计和孩子资料从不共享。
4. 删除教材前查询仍在引用同一 PDF 或页图对象的其他材料/Snapshot；存在引用时保留对象。迁移保留已存私有教材，不批量把旧教材声明为公开可复用。

## Consequences

### Positive

- 亲戚家庭可由唯一超级管理员直接开通，登录和学习数据始终按 Household 隔离。
- 相同的显式公开教材避免重复原件、页面渲染和 Provider 分析调用。
- 儿童学习事实和家长审核不会因内容复用而混用。

### Negative / Trade-offs

- 需要新增对象引用/清理迁移、并发幂等和最后引用删除验证。
- 来源教材一旦获批，跨家庭复用其页图与 AI 派生内容；因此公开声明和目标家庭重新审核是强制门禁。
- 商业化仍需要邀请、恢复、TLS、限速、审计、数据保留、支持和成本模型，不能仅通过新增注册页完成。

### Risks and Mitigations

- 风险：删除一个孩子教材误删共享对象；缓解：对象引用计数或事务化等价机制，最后引用才清理，并覆盖并发删除。
- 风险：公开声明错误导致私有教材被复用；缓解：默认关闭，需每次上传显式声明，且仅接受 PDF、完整内容指纹匹配和来源图谱已批准。
- 风险：全局内容去重泄露教材存在性；缓解：匹配仅在已完成上传的私有导入事务内执行，响应和 UI 不返回来源、对象键或命中信息。
- 风险：超级管理员账号被滥用开通家庭；缓解：仅 `super_admin` 可调用，使用 Session/CSRF/幂等键并记录审计事件；忘记密码只能在受信服务器控制台显式恢复，公开注册仍不提供。

## Compatibility and Migration

- 兼容性：既有最早 `parent_admin` 迁移为唯一 `super_admin`，其余 `parent_admin` 迁移为 `parent`；每个既有孩子归属给本家庭最早可用家长。既有 `LearningMaterial`/`CurriculumSnapshot`、对象键和已发布教材保持可读，旧教材默认不参与跨家庭复用。
- 迁移步骤：迁移账户约束与角色、孩子档案的 `owner_account_id`，新增公开复用标记和来源 Snapshot 引用，允许页图对象键多引用；Web BFF/Flutter 从当前 Session 读取 Household。
- 回滚：优先前向修复。回退应用仍读取材料现有对象键；不删除材料、Snapshot、KnowledgeMap、学习记录或审计，孤立对象由受控清理任务处理。

## Validation

- 超级管理员、普通家长和孩子分别验证创建家庭/孩子的授权；新家庭登录后不能读取创建者家庭的孩子、教材或任务，普通家长也不能读写同家庭其他家长名下孩子。
- 两个家庭上传相同且明确声明为公开的 PDF 后，不重复调用解析/分析；两个目标 Snapshot 均须独立批准才可发布。
- 任一家庭删除教材后，另一家庭仍能读取私有原页并使用其自己的知识图谱；最后引用删除才清理对象。
- 覆盖跨家庭路径篡改、CSRF、全局用户名重复、重试、并发删除、公开声明错误、导出/删除、TLS 和商业化保留策略后，才可考虑公网开放。
