# API

FastAPI modular-monolith entrypoint for the study assistant. The current P0
slice exposes `/healthz` and synthetic Household-scoped ChildProfile/Device
routes. The `X-Demo-Household-Id` and `X-Demo-Role` headers are local/CI-only
principal adapters, not production authentication.

Example local request:

```bash
curl -H 'X-Demo-Household-Id: 00000000-0000-0000-0000-000000000001' \
  -H 'X-Demo-Role: parent' \
  http://localhost:8000/households/00000000-0000-0000-0000-000000000001/children
```

真实认证、端侧 SQLite、Profile 生产持久化与派生对象级联、Ubuntu 原生模型实测和生产部署仍未实现。Learning/Capture/OCR
事务仓储、私有 MinIO 预签名上传与服务端确认、Capture 对象级联删除的失败可重试编排、家长保存/立即删除图片、local/CI 家长删除顺序与幂等入口、`LocalOcrJob` 安全 Worker、Pillow 完整像素解码/EXIF 清理、构建期 SHA-256 校验的 PaddleOCR 模型供应链、预置模型目录 Adapter、规范化 OCR 候选结果事务持久化、固定 synthetic OCR eval 与 synthetic 测试已经存在；运行时关闭未锁定的文档去畸变模型和模型源检查，不接受模型网络下载或更新，也不接受或保留真实儿童图片。

模型镜像构建需要提供 `ocr-model-manifest.json` 中的官方归档和摘要；构建脚本会拒绝空摘要、非 HTTPS 来源、路径穿越、软链接以及缺少模型目录的归档。运行层包含 PaddleOCR/OpenCV/CPU runtime 所需的最小 `libgl1`、`libglib2.0-0`、`libgomp1` 系统库。

## Local commands

```bash
uv sync --locked
uv run ruff format --check .
uv run ruff check .
uv run pytest -m "not integration"
uv run uvicorn study_api.main:app --reload
```

`uv.lock` is generated by the approved toolchain bootstrap and must be checked
in before this subproject is considered runnable.

Copy the local-only storage variables from the repository `.env.example` into
your local environment before using Capture uploads. If they are absent, the
API deliberately keeps non-upload routes available but rejects upload issuance
without falling back to embedded credentials.
