# API

FastAPI modular-monolith entrypoint for the study assistant. The current P0
slice exposes `/healthz` and synthetic Household-scoped ChildProfile/Device
routes. The `X-Demo-Household-Id` and `X-Demo-Role` headers are local/CI-only
principal adapters, not production authentication.

Example local request:

```bash
curl -H 'X-Demo-Household-Id: 00000000-0000-0000-0000-000000000001' \
  -H 'X-Demo-Role: parent' \
  http://localhost:8000/households/00000000-0000-0000-0000-000000000001/children
```

Identity, PostgreSQL persistence, offline synchronization, domain tasks and AI
providers remain outside this slice.

## Local commands

```bash
uv sync --locked
uv run ruff format --check .
uv run ruff check .
uv run pytest -m "not integration"
uv run uvicorn study_api.main:app --reload
```

`uv.lock` is generated by the approved toolchain bootstrap and must be checked
in before this subproject is considered runnable.
